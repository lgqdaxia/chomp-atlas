# 贡献指南

欢迎通过数据或证明 Pull Request 为 **Chomp Atlas / Chomp 局面图谱**补充可核对的材料。适合提交的内容包括：来源更正、局面定义澄清、已审命题的准确录入、证书与证明链接、实际走法的几何核对，以及页面可读性和无障碍改进。

## 一份可审查的提交

请在 Pull Request 中说明要修正的条目、修改前后的陈述、证据来源及实际检查范围。涉及数学结论时，至少提供：

1. **命题与版本。** 给出稳定标识、版本或日期、准确陈述和参数范围；新版本说明它替代了哪一条旧陈述。
2. **局面定义。** 使用盒子并、柱高或等价的精确点集定义，声明坐标顺序、参数域和符号。截图可以辅助说明，不能代替定义。
3. **证据类别。** 区分证明、形式化、完整有限证书、有限计算、条件推论、猜想和未知。附原始来源与可访问的材料链接。
4. **依赖与未解处。** 列出实际使用的命题及其版本；仍需假设的内容明确写出，不以待证命题支撑“已解”状态。
5. **验证记录。** 说明检查了哪些数据、链接、几何等式或证明对象，以及没有覆盖的范围。

一个参数点的证书应归到该点或明确的子族；不要把它登记为全族定理。提交更强命题时，须保留原命题和原证据的版本关系。

## 实际走法与证明关系

新增实际走法边时，请给出起点、仍然存在的非毒落子、精确后继，以及可能使用的坐标置换。可以直接核对

\[
X\setminus\uparrow v=Y
\]

或注明置换后的等式。无限局面的核对须使用完整符号表示；有限窗口中的点集一致，不能证明整个无限棋盘一致。

新增证明依赖时，请注明它承担的逻辑作用，例如“此归约使用该引理”或“此参数范围由该证书覆盖”。包含关系、文献引用和多口可达关系不能登记成一次安全走法。

把 X 登记为 N，需要一个已证 P 后继；把 X 登记为 P，需要全部安全后继为 N 的完整覆盖。更正其中一条边时，也要检查引用这条边的结论是否仍然成立。

## 数据和证明材料

局面数据与证明文字应分开维护，并使用稳定标识相互连接。显示名称可以改进；标识、参数意义和版本不可在未说明的情况下换成另一个对象。特别要区分完整主棋盘 W 与局部族 W(n,k)，以及不同定义下同名字母的高度参数。

数学状态发生变化时，请同步修改状态、适用范围、证据和待解问题。对旧结论的反例也应写明它反驳的是辅助命题、放松模型，还是实际 Chomp 轨道；三者不能混用。未完成或中断的计算保持未知。

新证明可以作为待审材料提交。网站在完成相应的命题和证据审查前，不据此发布新的“已证明”状态。AI 代理复核、人类审稿和形式化核验分别注明，不相互代称。

## 合并前检查

- 站内链接指向已存在的页面或条目；引用链接对应所述版本，页面中不残留作者电脑的文件路径。
- 局面标识和关系端点存在，参数上下界、自然数与序数约定一致。
- 实际走法通过合法性和精确后继检查；无限部分有符号证明或明确的已审来源。
- P/N 标签与证据范围一致，族结论保留完整量词，不把有限样本升级为无限结论。
- 证明引用和审计记录可定位，未完成证书不混入完成态材料。
- 在桌面与窄屏上检查公式、关系图、链接和键盘导航。

站点构建与内容检查只应读取所提交的数据和材料，检查结构、链接以及已声明的几何关系；它们**不会自动求出新的 P/N、Grundy 值、唯一 P 高度或获胜策略**。页面改版也不会自动重跑历史数学计算或扩大验证范围。需要新的数学求值时，应另行明确提出问题、方法、范围及停止条件。

阅读[规则与阅读方法](/rules/)和[证明与证据](/proofs/)，可了解这些审查要求所使用的术语。
