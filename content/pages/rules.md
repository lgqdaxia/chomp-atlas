# 规则与阅读方法

Chomp Atlas / Chomp 局面图谱研究的无限主棋盘是逐坐标偏序下的 \(W=\mathbb N^3=\omega\times\omega\times\omega\)，其中 \(\mathbb N=\{0,1,2,\ldots\}\)。这里的三个坐标都取有限自然数；\(\omega\) 表示轴没有有限终点，并不是原棋盘上可以点击的坐标。

## 一步怎样落子

局面 \(X\) 是包含原点的下闭点集：一个点还在，它在三个坐标方向上的所有下方点也在。原点 \((0,0,0)\) 是毒块，选择它立即输。

安全走法选择一个**仍在棋盘上的非原点** \(v=(a,b,c)\)，删除

\[
\{(x,y,z)\in X:x\ge a,\ y\ge b,\ z\ge c\}.
\]

三个不等式须同时成立，删除区域包括选中的点。图谱的实际走法边只记录安全走法；只有毒块的局面没有安全后继。

例如，在完整棋盘咬 \((1,1,1)\)，剩下三个坐标平面的并：

\[
T=\{(x,y,z)\in\mathbb N^3:\min(x,y,z)=0\}.
\]

从一张无限棋盘选择一个点，可能一次删去无穷多个点。它仍是一次走法。

## P 和 N 表示什么

P 表示轮到行动的一方在双方最优行动时必败，N 表示轮到行动的一方可以获胜。对一局的起始棋盘，P 就是后手胜，N 就是先手胜；它们不是经验胜率或随机对局比例。

- 一个局面是 N，当且仅当至少有一个安全走法到达 P。
- 一个局面是 P，当且仅当全部安全走法都到达 N。
- 只有毒块的局面是 P。

无限棋盘不导致和局。\(\mathbb N^3\) 的逐坐标偏序是良拟序，合法落子的序列不能无限延续，因此每条对局都在有限步后结束。这不表示存在统一的有限步数上界，也不自动提供判定所有局面的有限时间算法。

有些文献使用允许吃原点、空局面值为 0 的辅助正常玩法 Grundy 值 \(G\)。在该约定下，非空毒块棋盘为 P 对应 \(G=1\)，而不是 \(G=0\)。图谱若引用这种辅助值，会明确标明约定；不能把它与禁止吃毒块的安全走法 Grundy 值混用。

## 怎样读无限局面的表达式

原点盒子

\[
[a,b,c]=\{(x,y,z):x<a,\ y<b,\ z<c\}
\]

用边长表示局面；边长为 \(\omega\) 时，该方向包含所有自然数坐标。盒子并表示集合的并，重叠点只算一次。边长为 0 的盒子为空。

有限盒子可以完整画出；无限柱或无限平面的展示窗口只是示意。窗口之外仍然存在的点须由 \(\omega\) 标记和精确表达式说明，不能用有限画面替代定义。

局面族用参数描述无限多个棋盘。一个参数点已判 N，不代表全族已判 N；一个有限参数区间全部已判，也不能填补其余自然参数或参数 \(\omega\)。例如，局部族 \(W(n,k)\) 与完整主棋盘 \(W=\mathbb N^3\) 是不同对象。族条目会列出参数域、已证范围和剩余缺口。

辅助证明有时把柱高扩展到大于 \(\omega\) 的序数。这会产生另一个棋盘，允许的落子也随之变化。原 \(\mathbb N^3\) 中没有高度为 \(\omega\) 或 \(\omega+1\) 的落子点，辅助高度结论不能直接当作原棋盘的获胜首步。

## 两类关系图，两个问题

**实际走法图**回答“能否一口走到那里”。箭头从原局面指向后继，须有合法落子坐标及精确剩余点集；使用坐标置换时也须注明。沿边 \(X\to Y\)，若 Y 是 P，就得到 X 是 N；若 Y 是 N，仅能排除这一口为 X 的获胜走法，尚不能判 X 是 P。多口路径抵达 P，也不等于路径起点有一口到 P。

**证明依赖图**回答“这个结论依赖哪些命题、归约或证书”。它可以连接定理、参数族和局面，不要求每条边都是一次合法咬法。包含关系、参数下界或审计关系也不应显示成实际走法。

因此，证明 P 必须覆盖全部安全走法，包括全部无限参数口族；证明 N 只需一个已证 P 后继，并说明进入该后继后的应答策略。节点之间存在一条线，不能独自承担这些证明责任。

## 证据覆盖到哪里

图谱区分以下几类材料：

| 类别 | 能支持的结论 |
| --- | --- |
| 已审证明与完整策略 | 在明确假设和参数范围内支持相应定理；无限结论须包含无限口族的证明 |
| 形式化证明 | 支持指定形式系统中实际声明并通过检查的命题，范围由形式化对象限定 |
| 完整有限证书 | 在声明的有限局面及闭合后继范围内支持 P/N；不自动覆盖无限母形 |
| 有限计算与几何检查 | 支持实际检查的样本、走法或集合关系；不能由无反例推出全域定理 |
| 条件命题、猜想与未知 | 标明尚缺的假设或证明，不使用“已解”状态 |

有限搜索没有找到 P，不等于不存在 P；资源中断或缺少缓存的局面也保持未知。几何检查证明“一口后的形状正确”，不会单独证明形状的 P/N。
