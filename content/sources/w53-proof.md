# W(5,3) 的完整 P 策略与两条参数线

日期：2026-10-14，第31轮。采用零基坐标，原点为毒块，

\[
W(n,k)=[2,1,\omega]\cup[2,3,k]\cup[3,1,n].
\]

**已证 W(5,3)=P。因而整条 k=3 行仅 n=5 为 P，整条 n=5 列仅 k=3 为 P。** 参数域分别为自然数及 ω。按字面盒子并取 n 或 k>ω，所得局面仍下闭，但新增盒子会同时抬高背景两列，已离开本轮固定两条 ω 柱的家族；本轮未分类这些更高 ordinal 参数。

本轮只顺序完成 W(2,3)、W(3,3)、W(4,3)、W(5,3)。首次 P 命中后立即停止，W(6,3)…W(10,3) 没有启动，也没有构造其它 k。

## 2. 根、真实相邻裁切与49个低高度值

记

\[
E=\{(x,y,z):x\in\{0,1\},\ y\in\{1,2\},\ z\in\{0,1,2\}\}
\cup\{(2,0,z):0\le z<5\}.
\]

W(5,3) 为两完整相邻 z 塔加 E。全部安全口准确分为相邻塔 (1,0,a)、global (0,0,j) 和 E 的17点。

对相邻塔口 (1,0,a)，先真实裁切

\[
E_a=E\setminus\uparrow(1,0,a),\qquad
\widetilde H(a)=H_{E_a}(a).
\]

此处 a=0,…,4 不能用未裁 E 代替 E_a，因为未裁 E 的合法相邻高度下界为5。\(\widetilde H(a)\) 是裁切后原点塔的唯一 P **总高度**，回复为 (0,0,\(\widetilde H(a)\))。

全部低值如下；每行的值依左列 a 从小到大对应：

| a | \(\widetilde H(a)\) |
|---|---|
| 0…6 | 6, 2, 7, 10, 5, 15, 14 |
| 7…13 | 12, 9, 11, 17, 13, 19, 16 |
| 14…20 | 21, 23, 18, 24, 20, 22, 27 |
| 21…27 | 28, 25, 30, 26, 32, 33, 29 |
| 28…34 | 31, 37, 38, 39, 34, 35, 36 |
| 35…41 | 42, 43, 40, 45, 41, 47, 48 |
| 42…48 | 49, 44, 46, 53, 54, 55, 51 |

对全部 a≥49，

\[
\boxed{\widetilde H(a)=a+d_{a\bmod48}.}
\tag{1}
\]

所有低值及尾值均严格大于 a，所给 global 回复合法且到 P。

\[
\boxed{(1,0,j-e_{j\bmod48})}
\tag{2}
\]

即到 P：令 a=j−e_(j mod48)，则 0≤a<j，且 \(\widetilde H(a)=j\)。相邻口与 global 口的实际删上集可交换，因此先被截为有限 j 并不影响此回复证明。

根原始 FSM 尾阈为190、周期48，在有限状态190和238处证明同一状态重复；原始 global 逆尾阈为198。策略只读精确前缀，核对至这些已证阈值，得到式(1)最小起点49、式(2)最小起点56。48是所保存偏移数组和逆数组的最小周期。这些结论来自已证明的尾加有限前缀桥接，非观察若干重复值后猜测。

## 4. 全部 global 口与四个真实例外

\(\widetilde H\) 在自然 a≥0 上单射：若两种相邻口产生相同 P 总高，则较大相邻高度的有限 P 可以再裁到较小者，形成 P 到 P 的合法口，矛盾。由49个低值、周期尾和余数置换可精确确定其像：

\[
\boxed{\operatorname{im}\widetilde H
=\mathbb N_{>0}\setminus\{1,3,4,8\}.}
\tag{3}
\]

因此以下规则覆盖所有 global 口 (0,0,j)：

* j≥56，使用式(2)。
* 1≤j<56 且 j∉{1,3,4,8}，取唯一 a<j 满足 \(\widetilde H(a)=j\)，回复 (1,0,a)。这只需反查第2节表；a=49,…,54 时用式(1)，至多55个明确条目。
* 四个无相邻 P 回复的例外使用下表。

| j | 实际 P 回复 |
|---:|---|
| 1 | (0,2,0) |
| 3 | (0,1,2) |
| 4 | (0,2,2) |
| 8 | (1,2,2) |

完整 JSON 在一些本来也有相邻回复的低 j 处优先记录了另一个合法侧口；正文统一选相邻回复。两种选择均由同一唯一高度接口证明，不能把“保存策略恰选侧口”误读为“没有相邻回复”。

尾偏移平均值恰为5，式(3)中缺4个高度。这个计数只作已审实际像的交叉核对；四个具体例外还逐项通过了完整低 global 策略核查。

## 6. 整条 k=3 行与整条 n=5 列

首先，

\[
\boxed{W(n,3)=P\iff n=5,
\qquad n\in\mathbb N\cup\{\omega\}.}
\]

n<5 时，W(n,3) 是已证 P 根 W(5,3) 的实际口 (2,0,n) 子，故 N；源证书还给出第1节 n=2、3、4 的明确 P 回复。n>5 包括 ω 时，实际口 (2,0,5) 准确回到 W(5,3)=P，故 N。n=0 可删全部前部到两相邻完整塔 P；n=1 也可在 (0,1,2) 将前部截到已证 W(1,2)=P。故整行不再依赖任何未完成目标。

其次，

\[
\boxed{W(5,k)=P\iff k=3,
\qquad k\in\mathbb N\cup\{\omega\}.}
\]

k<3 时是 W(5,3) 的实际前部口 (0,1,k) 子，故 N；也有明确的已证 P 回复：

| k | W(5,k) 的实际获胜口与 P 根 |
|---|---|
| 0 | (2,0,0)，到两相邻完整塔 P |
| 1 | global2，到已证十点 P [3,1,2]∪[2,3,1] |
| 2 | (2,0,1)，到已证 W(1,2)=P |

对 k>3 包括 ω，实际口 (0,1,3) 只截前部，完整背景塔和侧链保持，准确回到 W(5,3)=P，所以 N。上述 k=1 的有限核见旧证书提取（原项目文件 `../../j_focus30/W31/W31_N_existing_certificate_extraction_zh.md`；本版未收录），k=2 的 P 根见[第30轮完整策略](w12-proof.md)；没有为这些参数新增构造。

\[

\]
