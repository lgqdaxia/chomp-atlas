# W(1,2) 的完整 P 策略与 k=2 行分类

日期：2026-10-14，第30轮。记

\[
W(n,2)=[2,1,\omega]\cup[2,3,2]\cup[3,1,n],
\qquad n\in\mathbb N\cup\{\omega\}.
\]

**已证 W(1,2)=P，因此整条合法 k=2 行满足 W(n,2)=P 当且仅当 n=1。** W(2,2) 没有启动独立构造：在首个目标命中 P 后按约定停止，所有 n>1 均可实际切回 n=1。

这里的 n 域不能直接扩成所有序数。本族要求前两列固定只有 ω 高；若仅将独立第三列延长到 n>ω，则它高过其下方前两列，点集不再下闭。若按字面的下闭盒子 [3,1,n] 取 n>ω，盒子并本身仍下闭，却会同时抬高前两列，已离开固定两ω柱的家族。本文的整行分类仅限自然 n 及 ω。

## 2. 相邻塔口：四个低值加偶奇公式

所有坐标先在 W 的标准坐标中给出。对手若在相邻塔口 (1,0,a)，a≥0，下口，有限侧部必须同时真实裁为

\[
E_a=E\setminus\uparrow(1,0,a).
\]

设 \(\widetilde H(a)=H_{E_a}(a)\)，即**裁好侧部之后**原点列的唯一有限 P 总高度。完整公式为

\[
\widetilde H(0)=4,\quad
\widetilde H(1)=2,\quad
\widetilde H(2)=7,\quad
\widetilde H(3)=5,
\]

\[
\boxed{
\widetilde H(a)=
\begin{cases}
a+2,&a\ge4\text{ 且 }a\text{ 偶},\\
a+4,&a\ge5\text{ 且 }a\text{ 奇}.
\end{cases}}
\tag{1}
\]

回复实际 global 口 \((0,0,\widetilde H(a))\) 即到 P。所有值都严格大于 a，因此相邻塔截断不会妨碍这个回复。a=0、1 时 E 尚未完整保留，不能把未裁侧部直接代入 H_E(a)；上式和策略文件都使用 E_a。

式(1)不是观察几个值后猜周期。根已审 FSM 从54起给出精确周期4；其偏移数组本身缩为周期2。已保存的有限前缀逐项核至54，最后一个不满足偶奇式的参数为3，故公式从4起对全部 a 成立。

## 3. global 口：七个低值加偶奇逆公式

用 j 表示当前 global 口高度，避免与 W(n,2) 的行参数 n 混淆。对手在 (0,0,j)，j≥1，下口后，按下表回复：

| j | 回复 |
|---:|---|
| 1 | (0,2,0) |
| 2 | (0,1,0) |
| 3 | (1,2,1) |
| 4 | (1,0,0) |
| 5 | (1,0,3) |
| 6 | (2,0,0) |
| 7 | (1,0,2) |

对全部 j≥8，回复

\[
\boxed{
\begin{cases}
(1,0,j-2),&j\text{ 偶},\\
(1,0,j-4),&j\text{ 奇}.
\end{cases}}
\tag{2}
\]

合法性与 P 性直接由式(1)给出：所得 a 满足 0≤a<j，且 \(\widetilde H(a)=j\)。先截相邻塔再截 global 与反序两口删去同一个上集并，故实际有限结果相同。低表逐项记录在完整策略文件。

从式(1)还得到一个精确的策略事实：全部自然 j 中，**仅 j=1、3 不能通过相邻塔口回复到 P**。因为 \(\widetilde H\) 的像准确为

\[
\{2,4,5,7\}\cup\{6,8,10,\ldots\}\cup\{9,11,13,\ldots\}
=\mathbb N_{>0}\setminus\{1,3\}.
\]

低表在 j=2、6 也选择了侧口，只是选择一种合法 P 回复，不能据此把它们误计为“没有相邻回复”的例外；例如 j=2 可取 a=1，j=6 可取 a=4。

## 4. 九个有限侧口的全部回复

剩余口恰为 E 的九点。下表全部已在冻结40行 PN 及实际坐标裁切中核对；“有限”或“无限”说明回复后 P 根的类型。

| 对手侧口 | 回复 | P 根类型 |
|---|---|---|
| (0,1,0) | (0,0,2) | 有限 |
| (0,1,1) | (1,2,0) | 较小两塔无限 P |
| (0,2,0) | (0,0,1) | 有限 |
| (0,2,1) | (1,1,1) | 较小两塔无限 P |
| (1,1,0) | (0,0,1) | 有限 |
| (1,1,1) | (0,2,1) | 较小两塔无限 P |
| (1,2,0) | (0,1,1) | 较小两塔无限 P |
| (1,2,1) | (0,0,3) | 有限 |
| (2,0,0) | (0,0,6) | 有限 |

例如最后一行的有限 P 根准确为

\[
[2,1,6]\cup[2,3,2],
\]

点数20。四行无限回复只落入已冻结的更小侧部 P 根，没有以尚未解决的无限母局面为依据。

相邻塔口、global 口和九个侧点覆盖根的全部安全口。每种对手口都已给出实际 P 回复，故以上是一套完整 P 策略，不只是有限表段。

**返回 P 后的续行规则。** 若已进入有限 P 棋盘，每次对手下口后，用严格按点数下降的有限毒块 PN 递归找到一个 P 子并回复；这对每个实际有限棋盘必停止，不需要预先枚举全部高度。若进入表中的较小两塔无限 P，则使用源证书对应侧部 F 的同一规则：有限侧口后的 N 记录已存实际 global 或侧口 P 回复；相邻口后，用真实裁切 F′ 的 H_{F′}(a) 回复 global；global 口后进入已知有限 N，使用有限递归寻找 P 回复。40行对全部这些侧部依赖闭合。每次仍保留两无限塔的侧口都严格减少有限侧点，因而不可能无限次停留在这类侧口中；一旦使用塔口，回复后即进入有限阶段。这样给出了持续到终局的策略算法，而非只给根的一轮回复。

## 5. k=2 行的全部合法 n 及 Y₇ 坐标接口

现在证明

\[
\boxed{W(n,2)=P\iff n=1,
\qquad n\in\mathbb N\cup\{\omega\}.}
\]

* n=1 已由完整证书证明 P。
* n=0 是 W(1,2) 的实际口 (2,0,0) 子，因此 N；上表还给出它的明确获胜 global6 回复到20点有限 P。
* 每个 n>1，包括 ω，合法口 (2,0,1) 准确把第三列截到1，保留另两部分，得到 W(1,2)=P，因此 W(n,2)=N。

该分类不需要单独构造 W(2,2)，也不需要追加更大的 n。此前 n≥3 的共同 global3 有限 P 证据可作为另一种策略，与第三列切回1相容。

返回七柱

\[
Y_7=[3,2,\omega]\cup[1,3,\omega].
\]

先下 (0,2,1)，再下 (1,0,2)，随后交换 x、y，即坐标置换 (1,0,2)，结果准确为 W(1,2)。故 Y₇ 的首口 (0,2,1) 后为 N，对方在 (1,0,2) 即到 P。两口也可交换次序；这给出已知另一个首口 (1,0,2) 后的无限 P 回复。

需要在 Y₇ 原坐标使用以上完整策略时，只须将每个标准坐标 (x,y,z) 换成 (y,x,z)。完整 JSON 同时保存了两套坐标及精确母局面。

这些接口排除具体首口，并不证明 Y₇ 的完整胜负。Y₇、J 与研究中的总母局面保持未判；本轮在完成此单一 P 根和整条合法 k=2 行后停止，不扩参数。
