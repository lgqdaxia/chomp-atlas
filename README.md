# Chomp Atlas / Chomp 局面图谱

从完整棋盘 **W = ℕ³** 出发的局面、真实咬法与证明导航。

网站：https://lgqdaxia.github.io/chomp-atlas/

本项目整理 Gaoqiang Liu 的研究材料。完整 W 的 P/N 仍未解决。局部已证结果、工作猜想、有限证据与条件结论分别记录。网站与检查程序不进行新的无限 P/N 求解。

## 本地运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run validate
npm test
npm run build
npm run dev
```

打开服务打印的本地地址。发布路径通过 `PAGES_BASE=/chomp-atlas/` 配置；开发构建默认 `/`，预览服务器也支持项目子路径。

## 数据与内容

- `data/atlas.json`：审定快照、局面、实际咬法、覆盖范围、命题和历史。
- `data/proof-sources.json`：公开原稿镜像白名单，记录原项目相对路径、原稿哈希和公开版哈希。
- `content/proofs/`：可读证明与精确范围。
- `content/sources/`：经过整理的自有原稿、核验报告和小型证书。
- `content/pages/`：规则、研究说明、贡献方式及有限三行成果。
- `src/geometry.js`：自然数棋盘的精确盒子并运算及 SVG 棋形显示。
- `scripts/build.mjs`：静态站点和数学公式构建。

完整 W、三层板 A₃、三平面裁轴 A₃ᵀ 和局部 W(n,k) 分别使用独立编号，避免旧稿别名冲突。坐标置换保存在咬法边上。

## 更新一个结果

1. 核对正式报告与对应审核，确定结果的真实适用范围。
2. 在 `atlas.json` 中更新命题、局面和参数覆盖；条件命题不得直接改写未知节点。
3. 加入明确选定的证明和核验材料，更新来源清单；保留旧结论的替代关系。
4. 执行 `npm run check` 和 `node scripts/check-links.mjs`，检查关键页面与移动端展示。
5. 通过 Pull Request 审阅后合并。主分支由 GitHub Actions 自动构建并发布到 Pages。

几何检查会核对每条登记咬法的精确后继，包括所有无限尾部；它不把有限绘图窗口当证明。P/N 真值由对应数学证明及适用范围内的核验材料承担，结构检查不能替代证明审阅。

## 发布材料范围

只发布本站明确列入的文件。大型原始证书按需另做版本附件；未镜像的依赖在证明页中标明，不随主页载入。原始研究目录、后台进度库、运行环境、临时文件和第三方论文全文均不自动上传。

源码与数学材料的授权沿用各自来源约定；本版未擅自为全部历史材料新增统一许可。
